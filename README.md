# batch-tools
一些轻量小脚本，个人Windows批处理小脚本合集

## ⚠️风险提醒
本仓库部分脚本会修改BitLocker等系统配置。
**使用前请仔细阅读源码，自行承担全部风险。**

## 脚本清单
- 模拟 hosts 权限：只有管理员才能使用或更改的文件
- 模拟 ProgramFiles 权限：只有管理员才能使用或更改的文件夹
- 删除import文件：用于删除Godot编辑器所产生的.import文件
- 重建Windows图标缓存：用于重建windows系统的图标缓存
- BitLockerTool：是BitLocker的管理工具（需要时windows系统专业版）
